## 4. 部署流程（deploy-mainnet.sh）

```bash
# 1) 生成全新 Program keypair（离线备份）
bash scripts/deploy-mainnet.sh --yes --generate-keypairs --dry-run   # 预览
bash scripts/deploy-mainnet.sh --yes --generate-keypairs             # 执行部署

# 2) 部署后初始化（真实资金前先小额冒烟）
#    初始化资金池 + 真实存款（把 init-localnet.mjs 换成主网 RPC/mint）
node scripts/init-localnet.mjs
#    初始化供应链注册中心
node scripts/init-supply-chain.mjs <真实供应商公钥...>
#    小额真实资金冒烟
node scripts/smoke-e2e.mjs
```
- 部署脚本内置：预检（强制）→ 构建 → deploy → 可选冻结 → `verify-contract-deployment.sh`
- 日志：`/tmp/deploy-mainnet-<时间戳>.log`
