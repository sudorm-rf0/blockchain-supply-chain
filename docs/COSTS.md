按 2026 年公开定价估算，实际以供应商账单为准。审计费用按你的要求不计入。

## 2. 推荐最低配置（每月）

开发/演示阶段：RPC 免费额度 + 自建 K8s（试用）+ MinIO 自建 + 自建 Postgres/Redis，
除域名约 ¥5-7/月外基本为 0。

正式轻量上线（低交易量）：

- Solana RPC：Helius 免费档或 Developer 档约 ¥0-350
- K8s：1 个 2C4G 节点约 ¥200-400
- 对象存储：¥20-50
- 域名 + CDN：¥20-50
- 托管 Postgres + Redis：¥300-500
- 合计：约 ¥550-1350/月

## 4. 一次性成本

- 域名注册：¥50-80/年
- 云资源开通（可能无月租，按量）：¥0-200
- 钱包与密钥管理工具：¥0（自管）

结论：演示/开发几乎免费；正式轻量上线最低约 ¥550-1350/月，大头是
托管数据库和云节点。若全部自建（K8s 单机 + MinIO + 自建 PG/Redis），
月成本可压到 ¥100 以内（仅域名与少量流量）。


## 5. 低用量场景：5 笔/日 · 先上线（不含审计 · 合规已就绪）

> 主网正式上线、用户量少、约 5 笔交易/日；2×VPS 自建（deploy/vps 方案）。
> 已排除：第三方审计、合规（KYC/AML/隐私等按已就绪处理）。

### 容量测算

- 链上：5 笔 × 每笔约 8-10 次操作 ≈ **50 txs/日**（可忽略）
- RPC：50 txs + indexer 快照 288/日 + 轮询 ≈ **500-2000 次/日**（平均 <0.1 RPS，
  但免费档主网月度配额约 2.5 万 credits/月，5 笔/日约 1.5-6 万，**免费档不稳**）
- 存储：约 50 文件/日 ≈ **1GB/年**；DB 忽略不计
