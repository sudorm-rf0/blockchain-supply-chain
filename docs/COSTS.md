# 上线技术成本估算（不含审计）

以下为 demo/devnet 到正式环境所需的第三方技术成本估算，币种为人民币，
按 2026 年公开定价估算，实际以供应商账单为准。审计费用按你的要求不计入。

## 1. 必选成本

| 项目 | 供应商 | 月成本估算 | 说明 |
| --- | --- | --- | --- |
| Solana RPC | Helius | ¥0（免费额度） | devnet 免费；正式环境若主网交易量大，Developer 档约 $49/月（约 ¥350） |
| 云 K8s 集群 | 阿里云 ACK / 腾讯云 TKE | ¥0（试用）~ ¥300 | 1 个 2C4G 托管节点约 ¥200-400/月，按量付费更贵 |
| 对象存储 | 阿里云 OSS / AWS S3 | ¥10-50 | 图片/PDF 存证，50GB + 少量流量约 ¥20 |
| 域名 | 阿里云/腾讯云 | ¥50-80/年（约 ¥5-7/月） | 普通 .com 首年，续费略高 |
| TLS 证书 | Let's Encrypt / 云证书 | ¥0 | 自动化续期 |
| Postgres 数据库 | 云 RDS 或 K8s 内自建 | ¥0-300 | 自建免费（随 K8s 节点），托管 RDS 2C4G 约 ¥200-400/月 |
| Redis | 云 Redis 或 K8s 内自建 | ¥0-150 | 自建免费，托管实例约 ¥100-150/月 |

## 2. 推荐最低配置（每月）

开发/演示阶段：RPC 免费额度 + 自建 K8s（试用）+ MinIO 自建 + 自建 Postgres/Redis，
除域名约 ¥5-7/月外基本为 0。

正式轻量上线（低交易量）：

- Solana RPC：Helius 免费档或 Developer 档约 ¥0-350
- K8s：1 个 2C4G 节点约 ¥200-400
- 对象存储：¥20-50
- 域名 + CDN：¥20-50
- 托管 Postgres + Redis：¥300-500
- 合计：约 ¥550-1350/月

## 3. 可选/弹性成本

| 项目 | 估算 | 何时需要 |
| --- | --- | --- |
| CDN（阿里云/Cloudflare） | ¥30-100/月 | 图片预览、前端静态资源加速 |
| 短信/邮件通知 | 按量 | 用户通知、告警 |
| 风控/OCR 服务 | 按量 | 单据自动识别、风控校验 |
| Sentry | ¥0-100 | 错误监控，免费档可用 |
| Grafana Cloud | ¥0-50 | 监控大盘，自建 Prometheus 免费 |

## 4. 一次性成本

- 域名注册：¥50-80/年
- 云资源开通（可能无月租，按量）：¥0-200
- 钱包与密钥管理工具：¥0（自管）

结论：演示/开发几乎免费；正式轻量上线最低约 ¥550-1350/月，大头是
托管数据库和云节点。若全部自建（K8s 单机 + MinIO + 自建 PG/Redis），
月成本可压到 ¥100 以内（仅域名与少量流量）。
